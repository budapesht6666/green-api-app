# Запуск проекта локально

Пошаговая инструкция: от клонирования репозитория до первого сообщения в Telegram. Занимает около 10 минут (большую часть времени занимает создание инстанса GREEN-API).

Онлайн-версия: https://greenchat.p1gog.duckdns.org · демо и скриншоты: https://greenchat.p1gog.duckdns.org/about/

## 1. Что понадобится

- **Node.js 20 или новее** (проверено на 24) и npm;
- аккаунт в [GREEN-API](https://console.green-api.com) (бесплатно);
- **два аккаунта Telegram**: первый подключается к GREEN-API как «отправитель», со второго вы будете отвечать. Отправить сообщение самому себе нельзя.

## 2. Установка и запуск приложения

```bash
git clone https://github.com/budapesht6666/green-api-app.git
cd green-api-app
npm install
npm run dev
```

Откройте http://localhost:5173. Для проверки собранной версии: `npm run build && npm run preview` (http://localhost:4173).

Бэкенда нет, переменные окружения не нужны: приложение обращается к GREEN-API прямо из браузера.

## 3. Получение idInstance и apiTokenInstance

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com) и нажмите **«Создать Telegram»**.
2. Выберите тариф **Telegram: Developer** (бесплатный). Инстанс создаётся до 2 минут: обновите страницу «Инстансы», пока он не появится в списке.
3. Откройте инстанс. В карточке указаны `idInstance` и `apiTokenInstance` (токен скрыт: нажмите значок глаза рядом с ним; значок со стрелками рядом меняет токен, его нажимать не нужно).
4. Авторизуйте инстанс в Telegram:
   - в Telegram на телефоне: **Настройки → Устройства → Подключить устройство**;
   - в карточке инстанса нажмите **«Получить QR»** и отсканируйте код (QR живёт недолго: если не успели, получите новый);
   - статус инстанса должен смениться на «Авторизован» (иногда пару минут идёт «Синхронизация»).

## 4. Сценарий проверки

1. **Вход.** Введите `idInstance` и `apiTokenInstance`. При неверных данных появится сообщение об ошибке.
2. **Уведомления.** У нового инстанса уведомления выключены, поэтому ответы не придут. В этом случае над чатом появится жёлтая плашка: нажмите **«Включить уведомления»**. Настройки применяются обычно за несколько секунд, максимум за 5 минут (инстанс перезапускается).
3. **Новый чат.** Нажмите «+» в списке чатов и введите номер получателя в международном формате (`+7 999 123-45-67`). Получатель: **второй** аккаунт Telegram.
   - Если Telegram «не находит» номер, у получателя закрыт поиск по номеру: *Настройки → Конфиденциальность → Номер телефона → Кто может найти меня по номеру → Все*. Либо введите его `@username`.
4. **Отправка.** Напишите сообщение (Enter отправляет, Shift+Enter переносит строку). У сообщения появятся галочки: ✓ отправлено, ✓✓ доставлено, синие ✓✓ прочитано.
5. **Ответ.** Со второго аккаунта ответьте на сообщение в Telegram. Ответ появится в чате за несколько секунд без перезагрузки страницы.

## 5. Ограничения тарифа Developer

- **3 чата** (собеседника) в месяц и 100 проверок номеров. После исчерпания квоты приложение покажет понятное сообщение (HTTP 466). Не создавайте лишних чатов: тот же человек, найденный по номеру и по `@username`, считается одним чатом, так как приложение всегда использует chatId.
- Сообщения из групп и каналов приложение игнорирует: по заданию нужны личные переписки.

## 7. Как устроено

```
src/api/         клиент GREEN-API (fetch), типы, тексты ошибок
src/state/       редьюсер чатов и сообщений, хранилище (sessionStorage / localStorage)
src/hooks/       получение уведомлений (long polling), автоскролл
src/components/  экраны и компоненты интерфейса
src/lib/         разбор номера телефона, форматирование
```

Используемые методы GREEN-API (Telegram):

| Действие | Метод |
|---|---|
| Проверка входа | `getStateInstance` |
| Номер или @username → chatId | `checkAccount` |
| Отправка текста | `sendMessage` |
| Получение сообщений и статусов | `receiveNotification` → `deleteNotification` |
| Проверка и включение уведомлений | `getSettings`, `setSettings` |

Хост API у каждого инстанса свой: `https://{первые 4 цифры idInstance}.api.green-api.com` (например, для `410022761607` это `https://4100.api.green-api.com`). Приложение вычисляет его само.

Учётные данные хранятся только в `sessionStorage` вкладки и пропадают при её закрытии. История переписки хранится в `localStorage` браузера отдельно для каждого инстанса.

## 8. Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| «Неверный apiTokenInstance» / «Неверный idInstance» | Проверьте значения в карточке инстанса; не путайте с id другого инстанса |
| «Инстанс не авторизован» | Отсканируйте QR заново (шаг 3.4) |
| Сообщения уходят, а ответы не приходят | Включите уведомления (плашка над чатом). Если плашки нет: в консоли GREEN-API у инстанса поле «Адрес отправки уведомлений (URL)» должно быть **пустым**, иначе уведомления уходят на этот адрес, а не в HTTP API |
| «На этом номере нет Telegram» | Номера нет в Telegram или он скрыт настройками приватности: см. шаг 4.3 или введите `@username` |
| «Исчерпан лимит тарифа Developer» | Использованы 3 чата: работайте с созданными или перейдите на платный тариф |
| Статус инстанса «Синхронизация» долго | Подождите несколько минут; кнопка «Перезапустить» в карточке инстанса |
